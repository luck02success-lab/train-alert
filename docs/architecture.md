# Architecture
Android calls the TypeScript API only. The API owns PostgreSQL state and a server-only `RailwayProvider`. RailRadar is called at `GET /v1/trains/{number}/live?date=YYYY-MM-DD` with a Bearer credential. Provider timestamps include an offset and are parsed into absolute UTC instants; schedule strings remain offset-bearing. A separately deployed worker will poll active journeys, update ETAs transactionally, create versioned alerts, and claim deliveries with row locking. FCM is intentionally not implemented.
